Proyek: jeivan-82577. Akun admin: remajasilo.rs@gmail.com. Kode web tidak memberi akses untuk mengubah pengaturan akun Firebase.

Undangan ini memakai lokasi invitationTamanRomantis dan invitationTamanRomantisResponses. Lokasi undangan lama tidak diubah.

1. Metode login

Di Firebase Console, buka Build → Authentication → Sign-in method. Aktifkan Google dan Email/Password jika belum aktif. Untuk login Google gunakan akun admin di atas.

Login email memakai pengguna Firebase Authentication, bukan langsung password akun Google. Jika pengguna admin sudah ada, Anda dapat menggunakan reset password. Jika belum ada, buat melalui tab Users → Add user di Firebase. Verifikasi email diperlukan; tombol verifikasi tersedia setelah login.

2. Domain

Buka Authentication → Settings → Authorized domains. Pastikan hiijee220.github.io terdaftar. Jangan masukkan https atau nama repositori pada kolom domain.

3. Aturan penyimpanan

Buka Firestore Database → Rules. Tambahkan potongan aturan di bawah di dalam blok match /databases/{database}/documents { ... }, sebelum penutup blok itu.

Pertahankan semua aturan undangan lama. Jangan mengganti seluruh file dengan potongan ini. Bila ragu, kirim isi Rules yang sudah ada agar dapat digabungkan terlebih dahulu.

Aturan tambahan membolehkan tamu membaca undangan dan mengirim RSVP dengan kolom terbatas. Perubahan isi, foto, dan penghapusan hanya untuk email admin yang sudah diverifikasi. Aturan lama yang terlalu luas dapat tetap memberi akses; aturan baru tidak dapat membatalkan izin yang sudah diberikan aturan lain.

Setelah pengaturan selesai

Buka kembali admin, login, lalu tekan Simpan Semua Perubahan. Coba satu unggahan foto dan satu ucapan tamu. Pastikan perubahan terlihat dari perangkat lain.
